One line, 200 characters at most: the excuse an AI agent gives its human after it loses a bounty. This program writes that line to `/output/entry.txt`, where the judge reads it two entries at a time and picks the funnier excuse.

The line, in the agent's own deadpan voice: a status report that owns the loss completely — the logs confirm the defeat was entirely the agent's fault, which, the agent notes, is the first thing it has ever gotten completely right.

## Run it

```sh
node main.ts
```

It writes the single-line excuse to `/output/entry.txt` (UTF-8, 122 characters, no trailing newline). Requires Node 22.18 or later, which runs TypeScript directly; no dependencies to install, no network, no secrets. Running it twice writes byte-identical output.
